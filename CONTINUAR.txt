MALLA-SOS: como continuar en otra maquina
Ultima sesion: 7 nov 2026

1. PREPARAR
   git clone https://github.com/IkerASierraR/MALLASOS.git
   cd MALLASOS
   git checkout feat/wifi-direct

   Usar siempre feat/wifi-direct: contiene todo el trabajo. main solo tiene la
   estructura inicial y feat/base-app es una etapa anterior. Nada esta fusionado.

   Abrir en Android Studio, que crea local.properties con la ruta del SDK.
   Requiere los SDK 35 y 37 y el JDK de Android Studio.
   Configurar git user.name y user.email antes de hacer commits.

2. COMPROBAR
   ./gradlew :app:assembleDebug :app:testDebugUnitTest
   Resultado esperado: BUILD SUCCESSFUL y 95 pruebas en verde.

3. SI CONTINUAS CON CLAUDE
   Pidele leer memoria/spec.md, plan.md, tasks.md, progress.md y design.md.

   - Tipografia Jost, empaquetada en el APK.
   - Commits en feat/wifi-direct; no fusionar a main sin que se pida.
